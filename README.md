# 문스쿨 CLASS WORLD v0.10

기준: main `b7dd89a` (PR #11 광장 카메라 오류 수정 포함).
작업 브랜치: `feat/campus-life-homes-expeditions`.

## 새 학교 생활 기능

- 생활 탭 → 출석·답장: 하루 1회 출석 보상 5 MC. 기분과 짧은 말을 수정해도 보상은 반복 지급하지 않습니다. 교사는 날짜별 출석과 기분을 확인합니다.
- 활동 탭 → 전체 활동 → 현황: 교사가 학생 제출에 300자 이내 답장을 남깁니다. 학생 생활 탭에 새 답장 알림과 받은 답장이 표시됩니다.
- 생활 탭 → 내 집·공터: 체험 학생 30명 각각의 집과 24칸 공터. 동네에는 6채씩 5개 구역이 있고, 집을 누르거나 근처에서 E를 눌러 방문합니다.
- 집 꾸미기 상점: 화단·나무·연못·벤치·야외 책장·텐트·가로등·조각상·분수·지붕 등 12종. 종류별 1개를 영구 보유하며 공터에서 배치·이동·회수합니다. 다른 학생의 집은 방문만 할 수 있습니다.
- 생활 탭 → 꾸미기: 기존 헤어·머리색·의상·액세서리 구매 기록과 새 신발 4종을 사용합니다. 기존 일러스트 또는 옷·헤어·신발이 반영되는 코드로 그린 꾸미기 캐릭터를 선택합니다. 새 구매·착용은 꾸미기 캐릭터로 전환합니다.
- 생활 탭 → 성장·탐험: 관찰 돋보기·꾸준한 물병·협력 배지가 대응 능력치 +2를 줍니다. 해당 탐험의 힌트를 열며, 학교 성적이나 이동 속도에는 영향을 주지 않습니다.
- 지식의 동굴·초록빛 탐험 숲·함께 오르는 탑: 전투 대신 각 3개의 지식 관문을 푸는 학습 던전입니다. 오답은 감점 없이 다시 생각하고 도전합니다. 각 탐험은 한국 날짜 기준 하루 1회 완료 보상 20 MC + 15 XP를 지급합니다.
- 탐험 진행·장식 배치·구매 기록·출석은 새로고침 후 유지됩니다. 새로운 저장 키 `classworld2d-campus-v010`을 추가하며 기존 저장 키를 지우거나 초기화하지 않습니다.

GitHub Pages 배포 후 새로고침하세요. 기존 데이터는 같은 브라우저와 기존 사이트 주소에서 유지됩니다.

별도로 제공되는 `문스쿨-v0.10-단일파일.html`은 school.js와 campus.js를 포함한 전체 HTML입니다.
기존처럼 index.html 한 파일만 교체하려면 이 파일을 index.html로 이름을 바꾸어 올릴 수 있습니다.

## 달라진 점

- 남녀 및 전후좌우 캐릭터 그림 유지. 좌우 반전과 실제 이동 방향으로 전환하며, 정지 시 방향 유지.
- 그림 전체의 수직 바운스 제거, 부드러운 카메라 이동. 휴대폰 실내에서는 캐릭터를 따라갑니다.
- 현재 일러스트는 정지 그림 3방향이므로 발을 번갈아 내딛는 실제 걷기 애니메이션은 아닙니다. 이를 위해서는 추가 원화가 필요합니다.
- 상시 안내, 중복 풍선, 탭 연결 수 표시 숨김. 미니맵·알림·도움말은 접힌 상태로 시작.
- 기존 활동 6개에 새 활동 9개 추가: 독서 기록 양식, 운동 안전 퀴즈, AI 사실 확인·개인정보 퀴즈, 나눗셈 퀴즈, 수업 돌아보기, 학급 제안, 매일 준비·건강 체크리스트.
- 교사: 다섯 유형 활동 생성, 정답·해설 설정, 투표 집계, 날짜별 제출 이력과 확인 처리.
- 학생: 장소 방문 후 수행·제출. 퀴즈 정답 시 1회 보상, 나머지 유효 제출 시 1회 보상. 오답도 제출로 기록되고 해설을 볼 수 있습니다.
- 일일 활동은 한국 날짜별로 1회 제출·보상. 이전 날짜 제출도 보존됩니다.
- 저장 실패 시 제출과 보상을 함께 되돌리고 안내합니다.

## 데이터와 한계

기존 `classworld2d-v03`, `classworld2d-v09-activities`, 수업·설정 키를 유지합니다.
학생별 문코인, XP, 성별, 옷장, 구매·장착 아이템, 기존 과제와 제출 내용은 초기화하지 않습니다.
새 활동은 최초 업데이트 시 한 번 추가됩니다. 삭제한 새 활동은 새로고침해도 재생성하지 않습니다.
기존 스타일 1 일러스트의 의상·헤어 별도 원화는 아직 없습니다. 생활 탭에서 선택할 수 있는 꾸미기 전용 그림체에는 실제 외형이 반영되며 구매·장착 기록은 유지됩니다.

**브라우저 로컬 체험판입니다. 다른 기기 간 실시간 동기화, 서버 인증, 안전한 교사 권한은 구현하지 않았습니다.**
출석·기분·답장·집 방문도 이 브라우저의 체험 기록입니다. 실제 반 학생의 기기나 교사에게 자동 전달되지 않습니다. 능력치와 던전은 학습 탐험용이며 실제 평가나 학생 간 순위에 사용하지 않습니다.
동일 브라우저 탭 간 기존 알림 기능은 있지만 서버의 동시 제출·보상 보장은 아닙니다.
브라우저 저장 데이터를 지우거나 다른 주소·기기로 열면 기존 기록을 불러오지 못합니다.

## 테스트

Node.js와 Playwright가 있는 환경에서 `npm install` 후 `npm test`를 실행합니다.
Windows Chrome을 기본으로 사용합니다. 다른 환경은 `CHROME_PATH`에 브라우저 실행 파일 경로를 지정하세요.
Playwright가 다른 곳에 설치되어 있으면 `PLAYWRIGHT_MODULE`로 모듈 경로를 지정할 수 있습니다.
테스트는 임시 브라우저만 사용하며 실제 학생 저장 데이터는 건드리지 않습니다.
결과 JSON 및 PC/휴대폰 스크린샷은 저장소의 상위 `qa` 폴더에 생성됩니다.
네트워크가 제한된 환경에서는 `SCHOOL_TEST_FILE=1`로 로컬 파일 모드를 선택할 수 있습니다. 생활 기능 테스트는 항상 임시 브라우저의 로컬 파일에서 실행합니다.
기존 기능 15개와 새 생활 기능 19개, 총 34개 확인 항목을 통과했습니다.

## v0.10.1 다른 사람에게 집 보여 주기

생활 → 내 집·공터 → 다른 사람에게 집 보여 주기 → 집 공유 링크 만들기·복사.
카카오톡이나 학급 게시판에 링크를 보내면 상대는 로그인 없이 집과 캐릭터를 구경할 수 있습니다.
별명·캐릭터 외형·지붕·배치한 장식만 링크에 담습니다. 코인·과제·출석 기록은 담지 않습니다.
공유 당시의 모습이므로 집을 바꾸면 새 링크를 보내 주세요. 방문자는 집을 수정할 수 없습니다.
**이 기능은 실시간 학급 공유가 아닙니다.** 실제 여러 기기의 학생 데이터·교사 확인을 연결하는 서버는 아직 배포하지 못했습니다.
home-share.js를 index.html과 같은 폴더에 함께 배포해야 합니다.
공유 기능 10개와 기존 34개, 총 44개 확인 항목을 통과했습니다. 독립 브라우저 방문, 개인 기록 보존, 잘못된 링크, 입력 검증, 휴대폰 화면을 확인했습니다.


## v0.10.2 달리기와 문 출입

Shift를 누르며 이동하거나 화면의 달리기 버튼을 켜면 약 1.7배 속도로 달립니다. 창을 벗어나면 달리기를 해제합니다.
실내 출입문 판정은 문 중심에서 0.65칸 이내로 줄였고, 입장 위치를 문에서 떨어뜨렸습니다. E키를 길게 눌러도 입장 직후 다시 나가지 않습니다. 실내 문 앞까지 이동한 뒤 E 또는 나가기 버튼을 누르세요.
movement.js를 다른 스크립트와 같은 폴더에 배포해야 합니다.
실시간 공유 서버는 인증 실행이 자동 권한 심사에서 차단되어 아직 배포되지 않았습니다. 현재는 브라우저 저장 및 집 스냅샷 링크만 지원합니다.


## v0.11 픽셀 캐릭터와 간결한 화면

독자 제작한 픽셀 캐릭터를 기본으로 표시합니다. 남녀·헤어·의상·신발 설정을 그대로 반영하며 저장 기록은 바꾸지 않습니다. 전후좌우 방향과 걷기/달리기 동작을 구분하고, 달리기에서는 보폭·팔 동작·무릎 높이와 동작 속도가 달라집니다.
지도는 접힌 메뉴로, 활동 내용은 가방/탭을 선택하면 열립니다. 상시 상태 설명·이름 풍선·버전 문구를 줄였습니다. 조작 도움말은 접힌 상태로 유지합니다. presentation.js를 다른 스크립트와 함께 배포해야 합니다.
다른 게임의 원본 그림을 사용하지 않습니다. 실시간 학급 동기화는 여전히 미완성입니다.

## v0.11.1 크기·동작·색상 조정
캐릭터 월드 높이를 약 106px에서 77px로 약 27% 줄였습니다(지도 확대율 적용 전).
대각선 이동 방향을 입력 기준으로 고정해 좌표 소수점 차이에 따라 머리 방향이 번갈아 바뀌지 않게 했습니다. 걷기·달리기 모든 프레임에서 머리 위치를 고정하고 상체 기울기와 달리기 동작 속도를 줄였습니다.
기존 색상 인덱스와 구매 기록을 보존하면서 선명한 파랑·빨강·초록·금색·보라 의상과 머리색을 적용했습니다. 지도 채도·대비를 소폭 높이고 화면을 남색·파랑·금색 계열로 정리했습니다.
기존 검증 58개와 머리 픽셀 고정·크기/팔레트·대각선 방향 검증 3개를 확인합니다.


## v0.11.2 캐릭터 가독성
캐릭터 모양과 안정된 머리 동작을 유지하며, 본체 크기는 약 8%만 키웠습니다. 내 캐릭터에 밝은 안쪽 외곽선과 남색 바깥 외곽선, 청록색 발밑 링을 추가했습니다. 움직이지 않아도 위치를 찾을 수 있으며, 이름·안내 글자를 추가하지 않았습니다. 윤곽선 이미지는 프레임별로 재사용합니다. 기존 기록과 화면 확대 설정은 유지합니다.
