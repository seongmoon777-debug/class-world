# Rounded MoonSchool character artwork

Created using the built-in image generation tool from the user-approved MoonSchool concept. No third-party game assets are included. `rounded-atlas.js` contains the WebP-encoded generated turnaround atlas. Original alpha is preserved in the encoded asset; the renderer discards near-transparent halo pixels for a clear silhouette. Runtime source rectangles select static heads and torso textures; arms and legs are Canvas geometry with separate walk/run poses. No student data is contained in this file.

Final generation prompt:
Create a clean production character turnaround atlas using the attached MoonSchool board as style and identity reference. Exactly SIX full body figures, 3 columns and 2 rows in equal rectangular cells on TRANSPARENT background. Large empty margins around ALL figures including bottom feet: every figure fills only 75% cell height. Top row: boy FRONT, RIGHT PROFILE, BACK. Bottom row: girl FRONT, RIGHT PROFILE, BACK. All figures identical height and baseline within each row, standing neutral, arms hanging slightly away from torso, legs straight slightly separated, shoes clearly visible fully inside cells. Match approved matte sculpted 3D cute human schoolchildren faithfully: boy rounded chestnut hair, blue button cardigan white collar ochre shorts; girl brown rounded bob, coral sweater white collar deep teal SHORTS (not skirt). White socks navy shoes. Preserve natural compact child proportion head one-third height. No text or labels, no shadows or floor, no layout lines. Complete six figures only, nothing clipped at image edges. Clear transparent space between arms and torso and between both legs for animated cutout rigging. Front and back arms symmetric in relaxed A pose, no bent elbows. Orthographic consistent lighting. Crisp silhouette, polished soft toy-like 3D.

The first proposed multi-frame atlas was rejected for clipped feet and repeated poses. It is not shipped.
